What was asked, and what is only recommended
Asked for Collapsible inline threads in orchestrator chats, on by default with a way to turn them off. A status on sent messages, and probably on received ones. Add and remove emoji reactions.
Recommended here, not decided The word "Finished" for a turn that ended (it does not mean the task is done). Reactions that agents never receive or read, and that are never approval, completion or a read receipt. Whether agents may add reactions. The setting kept per device. Rows kept in time order.
Status marks and the evidence behind each
Delivery mark Meaning Evidence that sets it
Clock Saved on this device Durable outbox entry, no host acknowledgement
Check On the host Host accepted the send, or its queue snapshot lists the item
Double check Delivered The recipient's timeline has the message row
Alert Not sent, or delivery unknown Host refusal, retry threshold, or an unknown-outcome receipt
Turn state Meaning Evidence that sets it
Spinner · Working The recipient's turn for this message is running The row's turn started and has no terminal event
Finished That turn ended. Not proof the task is done Turn completed event
Stopped / Turn failed That turn was cancelled or errored Turn cancelled or failed event
A delivery mark never becomes a turn state, and a reaction is neither.
